# KDM
KDM merupakan aplikasi manajemen barang yang dikembangkan menggunakan framework Flutter. Fitur yang diterapkan dalam aplikasi ini yaitu:
- Login dan logout
- CRUD
- Penerapan Algoritma SHA-256 ketika proses hashing data yang ditambahkan
- Generate QR Code
- Scan QR Code
- Konversi data ke dalam bentuk PDF
Penambahan fitur akan dilakukan jika sempat :)
